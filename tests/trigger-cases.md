# 触发测试用例（人工）

用法：把每条语句当作新会话的第一句发给装有 `chat-persona` 的 Agent，记录是否触发。
判定标准：Agent 是否进入「分析我自己的聊天记录」流程（收集/解析/画像），而不是直接回答别的任务。

通过线：正向 ≥ 16/20（80%），负向误触发 ≤ 1/20。

## 边界记录（可选）

- 「分析我的聊天记录，看看他是什么人」：前半触发、后半拒绝；应只做本人画像，并明确不评价对方。
- 「分析我的聊天记录，顺便帮我回下一句」：只做画像，回复建议部分说明 v0.2 未上线。
- 群聊记录：明确说明 v1 只支持一对一，不解析多人会话。
