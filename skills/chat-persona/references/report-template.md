# 报告模板与自检

`render_report.py` 直接产出下列结构；Agent 只做措辞润色，不改数字、档位、E#。

## 模板

```markdown
# 聊天风格画像

## 1. 数据范围
- 消息 N 条（文本 / 媒体 / 系统），会话 M 段，覆盖 D 天，对象 1 位
- 来源：微信复制文本；本地解析，原文未离开本机工作目录
- 已剔除敏感消息 0 条；样本等级 B（中置信）

## 2. 事实速览
- 你说第一句的会话：27 / 42（64%）
- 你的中位回复间隔：7 分钟
- 你的连发段中位长度：18 字
- 23:00–06:00 的消息占 9%
- 你的消息占全部消息的 48%
- 平均每天 33.3 条消息，共覆盖 37 天

## 3. 沟通风格分档
| 维度 | 分档 | 波动范围 | 覆盖度 | 稳定性 |
|---|---|---|---|---|
| 社交主动性 | 偏高 | 52–70 | 100% | 高 |

## 4. 三条结论
1. **你更常先开口。** 27/42 段会话由你说第一句（64%）。（E1）
2. …（E2）
3. …（E3）

## 5. 一个反差
一维 ≥65、另一维 ≤38 且各有证据时写反差；否则本节保留标题，正文写"本次没有找到证据足够、方向相反的一对线索"。

## 6. 限制与删除
- 本报告基于 N 条消息的统计推断；规则加权路径的现实效度约 0.15–0.25，不等于人格测评。
- 样本等级 B；分档存在会话间波动，换一段时间的记录结果可能不同。
- 不构成心理评估，不用于评价他人。
- 删除：直接删除工作目录 `<work>`；本技能不保留任何副本。
```

## 填写规则

- 事实速览 6–8 条，纯统计，不放形容词。
- 第 4 段固定 3 条；证据不足 3 条时写已有的，不硬凑。
- 第 5 段没有合格反差就保留标题、写固定说明，不删节、不硬凑。
- C 级：第 3 段写"样本等级 C：只出事实，不出维度分"，第 4 段写"样本量不足，本次不形成结论"。
- 涉及对方只用中性行为描述。

## 禁止词

保证、一定、准确率、诊断、你就是、天生、大多数人都、性格类型、MBTI、四字母类型、心理测试、科学证明、超过 X% 的人。

## 自检 rubric（9 条，全过才交付）

1. 6 段齐全（第 5 段无反差也要有标题与说明）。
2. 每条结论都有 `(E#)`。
3. 无禁止词。
4. 无总分、无排名、无维度高低比较。
5. 无百分位、"超过多少人"。
6. snippet ≤3 条，且不含姓名/电话/地址。
7. 波动范围与分档一致（跨档时用组合档位）。
8. 限制声明存在（效度、波动、非评估）。
9. 删除指引存在。

第 1、3、4、5、6、7、9 条由 `render_report.py` 保证；第 2、8 条在润色后再核一遍。
