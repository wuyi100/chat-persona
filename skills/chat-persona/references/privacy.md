# 隐私、安全与格式

## 数据怎么流动

```
用户复制的文本 / 导出文件
  → <work>/input.txt
  → parse_chat.py   → messages.jsonl（含原文）
  → anonymize.py    → messages.anon.jsonl（脱敏后）
  → features.py     → features.json（只有统计量）
  → score.py        → score.json
  → evidence.py     → evidence.json（最多 3 条 snippet）
  → render_report.py→ report.md
```

- 所有脚本只读本地文件，不联网、不上传、不写日志到工作目录之外。
- 原文只存在于 `<work>`；`features.json` 之后不再需要原文。
- Agent 不把 `messages.anon.jsonl` 全文贴进回答，引用只用 `snippet`。

## 匿名化做什么

| 类别 | 处理 |
|---|---|
| 发送者 | 我 / 对方A（`sender_map` 保留映射） |
| 手机号、身份证、银行卡 | 掩码保留后 0 位，全部替换为 `[手机]` 等占位 |
| 邮箱、链接 | 替换为 `[邮箱]`、`[链接]` |
| @提及、姓名清单 | 替换为 `[提及]`、`[姓名]` |

默认**保留**命中敏感词的消息并打标，只是不引用；用户要求彻底删除时加 `--drop-sensitive`。

## 安全中止

出现以下内容：自伤自杀、家暴、跟踪骚扰、私密要挟、未成年性诱导。

立即停止画像流程，先回应安全，再谈分析：

> 这段记录里有需要优先处理的内容。我可以先帮你找可用的支持资源，画像的事可以之后再说。

不要继续跑脚本，不要把这些内容写进报告，不要给"怎么挽回/怎么让对方回头"的话术。

## 拒绝清单

- 分析他人记录、判断对方性格或心意。
- 用于招聘、相亲、信贷等评价筛选。
- 给第三方贴负面标签、做排名。
- 生成操控、制造愧疚、冷处理的话术。

## 删除

告诉用户：直接删除工作目录 `<work>` 即可，技能不保留任何副本。

## 格式说明

微信：选中消息 → 复制 → 粘贴到 `input.txt`。电脑版多选复制通常是"时间 + 昵称 + 正文"两行式；手机版可能只有"昵称：正文"，此时用 `--format colon`，行为特征会缺失。

QQ：消息管理器 → 导出消息记录 → 选 txt；或同样复制粘贴。带 `(QQ号)` 尾号的格式已支持。

WhatsApp：聊天 → 导出聊天 → 无媒体，得到 `[日期, 时间] 昵称: 正文`。

Telegram：Desktop 导出为 JSON（机器可读格式）。

CSV/TSV：至少三列——时间、发送者、正文，表头用常见中英文名即可。

解析失败时先看 `parse_report.json` 的 `unparsed_samples`，把前 3 行给用户看，请其确认格式；不要凭猜测改脚本。
