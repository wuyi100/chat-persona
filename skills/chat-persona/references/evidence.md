# 证据口径

报告里的每一条结论都必须能落到 `evidence.json` 的一条记录上。没有证据的维度不写结论。

## 贡献度

对每个有分的维度：

```
贡献度_i = 权重_i × |项得分_i − 50| / Σ_j(权重_j × |项得分_j − 50|)
```

按贡献度降序取前 1–2 项。所有项都恰好 50 分时没有区分证据，该维进 `insufficient`，报告写"数据不足，未评估"。

## 一条证据包含

| 字段 | 说明 |
|---|---|
| `id` | `E1`、`E2`……报告引用 `(E1)` |
| `dim` / `dim_label` | 所属维度 |
| `feature` / `feature_label` | 特征 key 与中文名 |
| `stat` | 可读统计，必须带数字 |
| `claim` | 一句话方向（如"你更常先开口"） |
| `direction` | `high` / `low` |
| `contribution` | 在维度内的占比 |
| `snippet` | 可选，原文示例 |

## snippet 规则

- 只从**我的**文本消息里取，跳过 `sensitive=true` 的消息。
- 每条 ≤40 字，超出截断加"…"。
- 整份报告最多 3 条。
- 已匿名化，但仍要检查：不出现姓名、电话、地址、单位。

## 写法

结论句式固定为：**claim。** stat。可选"例如你说过：\"snippet\"。"（E#）

- 好："**你更常先开口。** 27/42 段会话由你说第一句（64%）。（E1）"
- 差："你是一个外向的人。"（无数字、无 E#、人格归因）

## 反差

只有同时满足才写反差内容：一维 ≥65、另一维 ≤38，且两维各有 ≥1 条证据。两条证据都要引用。不满足时第 5 段保留标题，正文固定写"本次没有找到证据足够、方向相反的一对线索"，不要用"但是""另一方面"硬凑。

## 无证据与低置信

- 维度 `score` 为 null：写"数据不足，未评估"，不解释、不推测。
- `stability=low`：该维降一档表述，并注明"不稳定"。
- 样本 C 级：只写事实，不写结论。

## 对方

只用中性行为描述（"对方的中位回复间隔比你的长"），不做人格归因，不猜动机。
