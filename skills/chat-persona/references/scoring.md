# 计分口径（v0）

本文件解释 `score.json` 的数字从哪来、能说到什么程度。脚本以 `assets/*.json` 为准，本文件是给人看的说明。

## 五维

| key | 对外名 | 只描述 |
|---|---|---|
| extraversion | 社交主动性 | 谁先开口、回得多快、连发多少、深夜聊不聊 |
| openness | 探索开放度 | 用字变化、提问频率、话轮深度 |
| agreeableness | 回应亲和度 | 附和、异议、是否接住对方的话 |
| conscientiousness | 条理规划度 | 消息完整度、是否落到时间和安排 |
| expressiveness | 情绪外显度 | 情绪词密度、感叹与重复语气 |

五维是**这段记录里的说话方式**，不是人格测评。名称里不带"性格""人格"。

## 权重

| 维度 | 项与权重 |
|---|---|
| 社交主动性 | initiation .30 / latency .25 / bursts .25 / night .20 |
| 探索开放度 | diversity .40 / question .30 / turn_depth .30 |
| 回应亲和度 | agree .40 / disagree .30 / coverage .30 |
| 条理规划度 | structure .50 / plan .50 |
| 情绪外显度 | emotion .50 / intensity .50 |

## 维度分与波动

- 维度分 = Σ(权重 × 项得分) / Σ(可用项权重)；覆盖度 <0.6 时不出分。
- 波动范围 = 按会话有放回重采样 1000 次（seed=42）得到的 P10–P90，含义是"换一批会话，分可能落在哪"。
- 会话数 <8 时不做重采样，`range` 为 null。
- 稳定性 = 随机删 30% 会话后分数的最大变化：≤8 高、≤15 中、>15 低。低稳定性的维度在报告里降一档表述。

## 分档

0–19 低 / 20–39 偏低 / 40–59 中 / 60–79 偏高 / 80–100 高。

波动跨档时 `band` 会给出组合标签（如"中偏高"），照抄即可，不要自己改。

## 样本分级

| 级 | 条件 | 输出 |
|---|---|---|
| A | ≥2000 条、≥30 天、≥3 对象 | 全部分档；可做同人不同时期对比 |
| B | ≥500 条、≥14 天 | 全部分档，标"中置信" |
| C | ≥200 条、≥7 天 | 只出事实与定性描述，不出分 |
| D | 其余 | 拒绝分析 |

一对一只有 1 个对象，最高 B 级。

## 不能做

不加总分、不排名、不比较维度高低、不给百分位、不做类型判定、不预测关系走向。
