评审对象：
- `Agent-Skill制作与开源执行清单(1).docx`
- `程序还是Skill-产品形态对照分析.docx`

评审立场：只问"在用户自己提供聊天记录、以 Skill 形态分发"这个前提下，哪条能站住。

## 二、A 级：不改会伤根基

### A1 把 0.35–0.43 当成自方案可达效度（最大的误读）

Park et al. 2015 的 0.38 来自 **66,732 人标注 + 数千维开放词汇 + 监督学习**。本方案是 **25 项规则加权**。Koutsoumpis et al. 2022 元分析显示 LIWC 单类别相关仅 0.10–0.14，最优线性组合现实量级 **0.15–0.25**。

- 后果：按 0.38 设计置信话术 = 把误差藏起来，拿自评量表一对就穿帮。
- 处置：可达效度写 0.15–0.25，文案只说"倾向/模式"。

### A2 百分位与置信区间不可算

原 §6.4"同龄前 30%，置信度中等"没有常模支撑；30 人校准集做不出年龄常模。

- 处置：删百分位；改会话级 bootstrap（1000 次）报 P10–P90，标注"会话间波动范围"；展示用分档 + 波动带。

### A3 六个观测项不可算或为伪信号

| 观测项 | 问题 |
|---|---|
| 承诺表述与兑现比 | 需外部世界状态，聊天里看不到"有没有做到" |
| 长词比例（≥6 字母） | 中文无空格、汉字长度固定，指标不存在 |
| 第一人称复数比例 | 中文主语高频省略，"我们"检出率不稳 |
| 冲突场景回应长度变化 | "冲突"未定义，规则判不准 |
| 深夜活跃 × 情绪词共现 | 两特征相乘 = 双重计分 |
| 新话题引入率 | 需话题分割，模型判断不稳 |

处置：v1 全部删除，进 v2 待验证；承诺类只保留"承诺表述密度"（测表达，不测兑现）。

### A4 中文短消息需按 burst 归一化

中文聊天一个想法拆 3–5 条。按单条算，所有人都会被算成"低表达、高连发"。原文档只提"长度归一化"，未提 burst。

- 处置：所有长度类特征按连发段（≤120s 同发送者）聚合后再算。

### A5 "端侧处理"与 Skill 形态矛盾

Skill 是给 Agent 的说明书；Agent 读到的内容已进入模型上下文。

- 可承诺的只有"最小暴露"：原文不出工作目录、脚本不回写原文、Agent 只读聚合 JSON。
- 处置：全文改为"最小暴露"，并写进 SKILL.md 与报告。

## 三、B 级：可信度与体验

| 编号 | 问题 | 处置 |
|---|---|---|
| B1 | 5–8 道自评题校准 5 维统计不成立，真实作用是提升准确感 | 删除计分用途；可选"偏好对齐" |
| B2 | 雷达图面积/形状随轴序变化，且暗示可比较 | 改横向条形图 + 波动带 |
| B3 | "反差观察"人人适用，会变成新巴纳姆 | 仅双证据时输出，否则删节 |
| B4 | 对外四字母标签与"不做类型判定"冲突，重测不一致会崩塌信任 | 删除，改分档命名 |
| B5 | "关系类型与目标必须问"太硬，杀使用率 | 一行假设 + 一键修正；仅安全场景强制问 |
| B6 | 采纳率/事后自评/第三方盲评在 Skill 形态不可测 | 会话内 rubric + 离线评测集 + 可选人工盲评 |

## 四、C 级：措辞与引用

- **C1** PIPL 第 24 条约束"自动化决策"，趣味自测通常不构成。做法对，依据应改为"按自动化决策标准自我约束"。另："性格刻画"不是法定敏感类别，敏感的是健康/宗教/性取向/未成年人信息。
- **C2** 数据源清单漏 WhatsApp；微信本地库加密、无合法导出，应直接写"不支持"；QQ 解析成本高，标 v2（后经用户决策改为"用户自己发文本"）。
- **C3** 工期估算（两周原型/四到六周可用版）对个人项目无意义，删除。

## 六、由评审导出的设计决定

1. 三层输出：L1 事实（脚本，永真）/ L2 倾向（推断，带区间）/ L3 叙述（模型，受引用约束）。
2. 观测项从 25 项砍到 14 项，其余进 v2。
3. 维度对外改名：社交主动性 / 探索开放度 / 回应亲和度 / 条理规划度 / 情绪外显度。
4. 报告固定 6 段，禁止词清单 12 条，自检 rubric 9 条。
